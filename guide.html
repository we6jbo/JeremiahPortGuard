JeremiahPortGuard User Guide

JeremiahPortGuard manages local port assignments, observes existing Linux listeners, reports conflicts, monitors computer resource pressure, and can consult WesternHillsAgent for supported informational questions.

SERVICE MODE CODE: PORTGUIDE

This is not a password. It only confirms that you have this guide before hiding the normal GUI. Capitalization and spaces do not matter.

Normal GUI Mode

After a fresh installation, JeremiahPortGuard starts automatically when you sign in to the graphical desktop and shows its normal window.

Run as Service

In the JeremiahPortGuard window, click Run as Service. The program asks for the code printed above. Enter PORTGUIDE. Variations such as portguide or Port Guide are accepted.

Service Mode disables normal GUI autostart, enables the JeremiahPortGuard systemd user service, and keeps the registry running in the background. The local status page remains available.

HOW TO BRING THE GUI BACK

Open a terminal and type:

jeremiah-port-guard gui-mode

This stops and disables Service Mode, restores automatic GUI startup, and opens the GUI.

You can also open the Manjaro application menu and choose JeremiahPortGuard - Restore GUI.

Local Status Page

While either mode is running, open a browser on this computer and go to:

http://127.0.0.1:23458/

The page is bound only to localhost. It shows operating mode, governor information, recent port conflicts, and WesternHillsAgent contact status.

Port Conflict Alerts

When JeremiahPortGuard detects a serious managed-port conflict, GUI mode can display a warning dialog. Repeated popups can be suppressed from the main window. Conflicts are still logged and remain visible on the local status page even when popups are suppressed.

Useful Commands

jeremiah-port-guard status
jeremiah-port-guard gui-mode
jeremiah-port-guard service-mode
systemctl --user status jeremiah-port-guard.service

Important: Keep this printed guide somewhere you can find it if you use Service Mode.
